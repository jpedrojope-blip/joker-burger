# About, Journal, Instagram Specification

## Overview
- Targets: `#about`, `#journal`, `.instagram`
- Interaction: static content plus hover zoom on Instagram tiles.

## Computed reference
- About is white with oversized black marquee text and two-column image/copy block.
- Journal background: `rgb(255, 238, 194)`; dark green text; rounded image cards.
- Instagram background: `rgb(243, 202, 98)`; six square image tiles.
