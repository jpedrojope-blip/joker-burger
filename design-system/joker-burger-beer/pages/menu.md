# Menu Page Override

**Page:** Dedicated Joker Burger e Beer menu
**Purpose:** Let hungry visitors browse by category and move to the Anota AI order flow quickly.

## Page Rules

- Keep the Joker brand palette: ink `#242426`, purple CTA `#9A3791`, lime accent `#8CD289`, green `#202622`.
- Use a bold food-led hero, then a horizontally scrollable category navigation with clear anchors.
- Group items into Smash burgers, Frango, Combos, Porções, and Bebidas.
- Never invent prices; show “Preço no app” and link each item to the supplied order page.
- Keep the WhatsApp action in the same fixed location as the home page.
- Preserve visible focus rings, 44px minimum touch targets, lazy-loaded images, alt text, and no horizontal overflow on mobile.

## UX Note

The UI search for `restaurant menu categories order CTA` reinforced keeping repeated help and ordering mechanisms in a consistent relative location across pages.
